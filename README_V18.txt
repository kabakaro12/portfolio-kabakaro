KABAKARO DEV — PATCH V18
==========================

Ce patch améliore le portfolio pour deux publics :
- recruteurs : CV, expérience et projets accessibles immédiatement ;
- clients : devis et rendez-vous plus visibles.

Modifications :
- domaine canonical/OG corrigé vers https://www.kabakarodev.fr/
- navigation simplifiée
- accueil recruteur / entreprise
- repères professionnels visibles
- G-Transport, 3D Services et Kabakaro Dev mis en avant
- étude de cas G-Transport
- projets secondaires allégés
- suppression de l'affichage "0 visites"
- nouveaux styles responsive

Installation :
1. Placer apply_v18.py à la racine du dépôt portfolio-kabakaro.
2. Vérifier qu'il est à côté de index.html et style.css.
3. Exécuter : python apply_v18.py

Sauvegardes automatiques :
- index.v17-backup.html
- style.v17-backup.css

Le script ne modifie pas script.js, les API, le système de devis ou les rendez-vous.
